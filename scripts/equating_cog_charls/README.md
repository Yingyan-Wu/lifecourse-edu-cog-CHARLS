# CHARLS-word-recall-equipercentile
This repo contains all the code necessary to replicate data construction and analyses in the paper:
Citation


Dataset: China Health and Retirement Longitudinal Study (CHARLS) (waves 2015, 2018, 2020)
Main measures: immediate word recall scores and delayed word recall scores


Methods: Equating using`equate` R package (Robitzsch, 2019) using the equipercentile method.

### Directory Descriptions
**RScripts**: RScripts are named in the order they should be run. Functions created by the authors were sourced where needed.
&nbsp;&nbsp;&nbsp;&nbsp;**1.dataset_export_equating_addw5.R**: This script cleans the data and creates the necessary variables for equating.
